# Nexus PDF (English Version)

Nexus Bench is a local PDF toolbox. 
It supports:
- Reading
- Watermarks (Layer / Raster)
- Page Management (Extract, Delete, Rotate)
- Merging and Splitting
- Exporting to Images
- Compression
- Encryption and Decryption

All operations are performed locally on your device without uploading anything to a server.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

*This is an English translation of the original Nexus Bench app.*
